## 2. 全局 UI 规范（全页面共用）

### 2.1 导航结构
- TabBar（3~4 个）：首页 / 分类或活动 / 订单 / 我的
- 统一顶栏：返回、标题、右侧按钮（分享可移除）

### 2.2 视觉设计 Token（WxSS 建议）
- 颜色
  - 主色：#FF6A3D
  - 辅助：#1F8A70
  - 强调：#FFC857
  - 背景：#F7F4EF
  - 卡片：#FFFFFF
  - 文字主色：#1D1D1F
  - 文字次色：#6B6B6F
  - 边框/分割：#E7E2D9
  - 危险：#E54545
  - 成功：#2EAD6C
  - 信息：#2F80ED
- 字号（rpx）
  - 标题 36 / 32
  - 正文 28 / 26
  - 辅助 24 / 22
  - 价格主数字 40
- 间距与尺寸（rpx）
  - 页面边距 24
  - 卡片内边距 20
  - 组件间距 16
  - 圆角 16（卡片）/ 12（按钮）/ 999（胶囊）
  - 阴影：0 8 24 rgba(0,0,0,0.08)

### 2.3 按钮状态
- 主按钮：主色填充 + 白字
- 次按钮：白底 + 主色描边 + 主色字
- 禁用：#D8D3C8 背景 + #A6A39C 文本
- Loading：按钮内左侧小 loading + 文本置灰

### 2.4 弹窗/Toast/骨架屏
- Dialog：标题 + 内容 + 双按钮
- Toast：顶部或中部，2s 自动消失
- Skeleton：卡片级灰块，圆角 12

### 2.5 权限与未登录引导
- 未登录按钮点击后弹出授权提示卡
- 权限未授予时，展示说明 + 授权按钮

## 3. 核心 UI 规则：二级价格解锁展示

### 3.1 出现位置（必须）
- 商品卡片（列表）
- 商品详情页价格区（主展示）
- 下单确认页（成交价展示）
- 我的页面（等级与累计消费可视化）
- 订单详情（价格快照）

### 3.2 文案与展示逻辑
- 未解锁（price_level=1）
  - 主价格：一级价
  - 辅助：累计消费满 2000 解锁二级价格
  - 可选：还差 ¥X（由后端返回或前端计算）
- 已解锁（price_level=2）
  - 主价格：二级价
  - 标识：已解锁徽标
  - 可选：已享受二级价格

### 3.3 视觉层级与标签
- 主价格：加粗、较大字号
- 次价格：小字号 + 弱色
- 标签：Lv1/Lv2 或 一级价/二级价徽标，避免歧义

### 3.4 PriceTag 组件定义（复用规范）
- Props
  - priceLevel: 1 | 2
  - priceLevelLabel: string（如“一级价/二级价”）
  - pricePrimary: number
  - priceSecondary: number（用于对比展示）
  - unlockThreshold: 2000
  - consumedTotal: number
  - distanceToUnlock: number（可选）
- Layout
  - 左侧：主价（¥ + 数字）
  - 右上：徽标（Lv1/Lv2）
  - 下方：提示文案
- 状态
  - Lv1：显示“累计消费满 2000 解锁二级价格”
  - Lv2：显示“已解锁”徽标

## 4. 页面级设计（用户端）

### 4.1 首页（Home）
- 布局结构
  - 顶部搜索栏
  - Banner 轮播
  - 分类入口（可选）
  - 商品列表（单列卡片）
- 组件列表
  - SearchBar、BannerSwiper、ItemCard、PriceTag、EmptyState、Skeleton
- 字段与校验
  - 搜索关键词：非必填，长度 <= 30
- 交互事件
  - 搜索输入 -> 回车/按钮触发 -> 刷新列表
  - 点击卡片 -> 商品详情
  - 下拉刷新 / 上拉加载更多
- 状态机
  - 加载：骨架屏
  - 空：无数据提示 + 去逛逛按钮
  - 错：网络错误 + 重试
  - 禁用：列表项不可点击（下架/过期）
- 跳转链路
  - 首页 -> 详情

### 4.2 商品列表/分类（List/Category）
- 布局结构
  - 顶部筛选条（分类/门店/价格等级提示）
  - 列表
- 组件列表
  - FilterBar、ItemCard、PriceTag
- 交互事件
  - 切换分类 -> 刷新
  - 点击商品 -> 详情
- 状态机
  - 加载/空/错同首页
- 跳转链路
  - 列表 -> 详情

### 4.3 商品详情（Detail）
- 布局结构
  - 轮播/大图
  - 标题 + 标签（上架/有效期/适用门店）
  - 价格区（PriceTag）
  - 详情说明（折叠/展开）
  - 悬浮底部：立即下单
- 组件列表
  - BannerSwiper、PriceTag、StatusBadge、Dialog
- 字段与校验
  - 商品状态：上架/下架
  - 库存：>= 0
- 交互事件
  - 立即下单：未登录 -> 登录引导
  - 展开详情/查看门店
- 状态机
  - 下架/过期：按钮禁用 + 提示
  - 库存不足：显示“已售罄/名额不足”
- 跳转链路
  - 详情 -> 选择时段

### 4.4 选择时段（Slot Picker）
- 布局结构
  - 日期选择（横向）
  - 时段列表（容量提示）
  - 底部确认
- 组件列表
  - SlotPicker、EmptyState
- 字段与校验
  - 必须选择日期与时段
- 交互事件
  - 选择时段 -> 高亮
  - 确认 -> 下单确认
- 状态机
  - 无可用时段：空态
- 跳转链路
  - 选择时段 -> 下单确认

### 4.5 下单确认（Order Confirm）
- 布局结构
  - 商品信息卡
  - 成交价区（显示 unit_price + price_level_snapshot）
  - 数量（可选）
  - 预约信息
  - 支付按钮
- 组件列表
  - OrderSummaryCard、PriceTag、Dialog
- 字段与校验
  - 必须选择时段
- 交互事件
  - 点击支付：按钮 loading 防重复
  - 成功 -> 订单详情
  - 失败 -> Toast + 重试
- 状态机
  - 按钮禁用：库存不足/状态异常

### 4.6 订单列表（Orders）
- 布局结构
  - 状态筛选（全部/待支付/已支付/已核销/已退款）
  - 订单卡片列表
- 组件列表
  - OrderCard、StatusBadge、EmptyState
- 交互事件
  - 切换筛选 -> 刷新
  - 点击卡片 -> 订单详情
- 状态机
  - 空态：引导去首页

### 4.7 订单详情（Order Detail）
- 布局结构
  - 状态区（大状态 + 说明）
  - 商品信息
  - 成交信息（unit_price、quantity、pay_amount、price_level_snapshot）
  - 预约信息
  - 核销区
- 组件列表
  - StatusBadge、Dialog
- 交互事件
  - 核销按钮：二次确认
  - 核销成功：显示核销时间与凭证样式
- 状态机
  - 已核销：按钮禁用
  - 未支付：隐藏核销入口
  - 已退款：隐藏核销入口 + 提示

### 4.8 我的（Profile）
- 布局结构
  - 用户信息卡（头像、昵称、手机号）
  - 等级卡（价格等级、累计消费、还差金额）
  - 功能入口
- 组件列表
  - ProfileCard、LevelCard、ListItem
- 交互事件
  - 登录/绑定手机号
  - 点击等级卡 -> 等级说明

### 4.9 等级说明（Level Guide）
- 内容
  - 一级/二级价格区别
  - 解锁条件：累计消费满 2000
  - 口径：核销成功订单实付金额
  - FAQ

## 5. 页面级设计（管理端）

### 5.1 登录
- 表单字段：账号、密码
- 校验：非空
- 失败提示：统一错误样式

### 5.2 商品管理
- 列表字段：标题、一级价、二级价、库存、有效期、状态
- 操作：新增、编辑、上下架
- 校验：二级价 <= 一级价

### 5.3 时段管理
- 列表字段：日期、时段、容量、已占用
- 操作：新增、编辑、停用
- 校验：时间段合法、容量非负

### 5.4 订单管理
- 筛选：订单号、手机号、状态、时间范围
- 列表字段：状态、金额、价格快照、核销状态、下单时间
- 详情：核销信息 + 价格快照

### 5.5 用户管理
- 列表字段：用户ID/手机号、累计消费、价格等级、解锁时间
- 查询：按手机号/用户ID
- 建议：只读为主，避免手工改动

## 7. 交互与状态机通用模板
- 加载：Skeleton 或 loading
- 空：EmptyState + 引导操作
- 错：错误提示 + 重试
- 禁用：按钮置灰 + 提示
- 权限：未登录/未授权提示
