Architecture

技术架构与工程拆解

这里把项目从“做了什么”拆成“怎么设计、怎么分层、怎么保证可维护”，更适合投系统开发和 Java 后端岗位。

业务系统分层

Client 微信小程序负责活动浏览、分类筛选、下单确认、订单详情、佣金中心和个人中心。
Admin Vue 3 管理后台负责活动、订单、用户、佣金、分类、轮播图、悬赏和上传维护。
API Spring Boot Controller 提供 RESTful 接口，统一返回结构、参数校验和后台鉴权。
Service Service 层处理订单状态流转、支付回调、退款规则、佣金结算、提现和邀请关系。
Data MyBatis + MySQL 承载用户、活动、订单、佣金、提现、悬赏、图集和初始化数据。

核心模块覆盖

活动域 活动、分类、俱乐部、轮播、时段、库存、上下架和图集上传。
交易域 下单、支付参数、支付回调、订单状态、核销、退款和订单导出。
增长域 邀请二维码、佣金账户、佣金记录、提现申请、悬赏任务和福利提交。
系统域 后台账号、接口鉴权、统一异常、文件存储、缺图检查和上传清理。
